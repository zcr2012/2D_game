# 配音清单

文件放在 `game/assets/audio/voice/`，没有文件时自动退回打字机音效。配音只念台词本身，不念括号里的舞台说明。

## 小眠（普通话，儿童向）

- 音色：统一的儿童向女声（`add_voice` 试听选定：明亮、咬字清楚，像陪孩子冒险的机器人伙伴）。
- **所有固定台词**都按文本算 id：`xm_<md5(去掉 BBCode 和空白的文本)前 10 位>.mp3`。
  游戏里 `Dialog.say("xm", 文本)` 自动找对应录音，不需要手写 id；`Audio.xm_id()` 和 `tools/xm_voice.py` 用同一算法。
- 范围：三个梦的剧情台词、碎片提示、异常数据反应、结局选择前的追问、诊所简报/回访、分析面板的开场白、
  “上次离开时……”回顾、**所有分支下的提示（按小眠此刻会说的内容）**、三种设备的操作提示、结局里小眠的一句话。
- 带按键名的句子（“按 Tab” / “点『编辑』”）用**去掉按键名**的版本配音，一条录音三种设备通用（`Plat.speech_of`）。
- 分析提示里的“还差：……”“另外，……”拆成两段录音依次播放（`Audio.voice_seq`）。
- **例外**：玩家接入联网 AI 后，小眠的分析和梦之人格的自由回答是现场生成的，无法预录，只显示文字。

### 流程

```bash
python3 tools/xm_voice.py manifest   # 扫描游戏，写 art_src/xm_lines.json（台词清单、id、优先级）
python3 tools/xm_voice.py chunks     # 生成还缺的批次 art_src/voice_work/chunk_NN.txt / .json
#   每批文本交给语音合成（同一个音色），保存为同名 chunk_NN.mp3
#   语音服务一次只接受约 60 个字，所以每批是 1~6 句短台词，按换行分开
python3 tools/xm_voice.py split      # 用停顿检测切成单句，写入 game/assets/audio/voice/xm_<id>.mp3
python3 tools/xm_voice.py check      # 覆盖率；有缺失时退出码为 1
```

台词改了以后重新跑 `manifest` + `chunks`，只会补录新的或改过的句子。

### 进度

**固定台词 287 句全部有录音**（`check`：0 / 287 缺失）；`smoke_station` 通关一次缺录音数为 0。没录到的句子（比如以后新增的台词）照常显示文字并播放打字机音效。

语音服务偶尔会拒绝个别句子，有两句录音的措辞与屏幕文字略有不同（意思一致）：

- “这是一张没有终点的星图……” → 录音念“这是一张看不到尽头的星图……”
- “……往东走，是走不出去的。” → 录音念“……一直往东走，会绕回来。”

想逐字对应，改成接口接受的说法后删掉对应 mp3，再跑 `chunks` 补录即可。
测试 `smoke_station` 会统计一次通关里缺录音的小眠台词数量。
